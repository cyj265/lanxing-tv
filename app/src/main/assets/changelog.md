# 更新日志

最新版本写在最上面，每发布一个新版本就在顶部加一段。
本文件同时用于两处：GitHub Release 的更新说明、App 内更新弹窗的"本次更新"（只显示最新版本这一段）。

## v1.16.5
- 设置面板新增「备份恢复」独立分类，不再放在「关于」里
- 恢复备份列表改为焦点行高亮，默认选中最新一份备份，一眼看清选的是哪份
- 统一设置面板焦点样式：焦点实心亮蓝加白字，选中项为半透明蓝，修复部分按钮焦点底色发灰、看不出来
- 修复焦点乱跳：内容区上下到边界回到左栏当前项、最右侧不再跳到「关闭」，同一行的多个选项可正常左右切换

## v1.16.4
- 频道列表工具条新增「只看收藏」与「设置」文字按钮，遥控器可左右切换，焦点高亮更明显
- 设置面板按键统一：返回键逐层退出、OK 进入详情、菜单/设置键关闭；切换分类回到顶部，低分辨率盒子的导航栏可滚动
- 备份/恢复重做：备份先写应用目录并显示路径，恢复直接列出应用内备份（带时间与大小），不再依赖系统文件选择器
- 修复部分盒子外部存储写入失败（ENOSPC）导致备份失败或备份为空，改为自动写入应用内部目录
- 修复恢复列表白底白字、文件名完全看不见的问题，并过滤写坏的 0 字节备份

## v1.16.3
- 频道列表工具条新增设置按钮，遥控器没有菜单键也能进入设置
- 备份/恢复补齐解码方式、自动更新、记住分组、分组折叠等偏好
- 检查更新在直连 GitHub 失败时自动切换加速线路
- 局域网管理页增加访问令牌，同网设备需扫描二维码才能打开
- Android 10 及以上开机自启被系统拦截时，改为发送通知提醒

## v1.16.2
- 修复没有系统文件选择器的 TV 盒子恢复备份时闪退，改为直接列出应用目录下的备份文件

## v1.16.1
- 播放内核 media3 升级到 1.11.1，修复 HLS/H.265 时间戳异常导致的播放失败
- 更新 appcompat、recyclerview、constraintlayout、zxing 等依赖到最新稳定版
- 收藏功能重新可用：频道列表工具条新增"收藏"按钮，列表中按菜单键、播放界面按信息/收藏键也能收藏
- 连按上下键换台加入防抖，只在停手后起播最终频道，避免频繁重建播放器导致解码失败黑屏
- 按 OK 打开频道列表时，右侧列表自动定位并高亮到当前正在播放的频道
- 修复 Android 8.0 及以上系统更新下载后装不上：首次更新会引导允许"安装未知应用"
- 切到后台自动暂停解码，回到前台自动续播，不再长期占用硬解资源
- 节目单按设置间隔自动刷新，盒子常年不关机也不会停在开机那一刻
